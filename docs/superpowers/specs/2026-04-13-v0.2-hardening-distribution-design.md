## SP1 — eBPF Process Capture with Aya / Capture processus eBPF avec Aya

### Goal / Objectif

Replace the unreliable 3-tier process resolution (ss socket table → /proc/net → listen port) with kernel-level PID capture using eBPF tracepoints. The existing `ProcfsProcessResolver` becomes the fallback.

Remplacer la résolution processus 3-tier peu fiable par une capture PID au niveau kernel via tracepoints eBPF. Le `ProcfsProcessResolver` existant devient le fallback.

### Architecture

```
┌─────────────────────────────────────────────┐
│ Kernel space                                │
│  tracepoint/sock/inet_sock_set_state        │
│  → captures (pid, comm, sport, dport, proto)│
│  → writes to BPF_MAP_TYPE_RINGBUF           │
└──────────────────┬──────────────────────────┘
                   │ ring buffer
┌──────────────────▼──────────────────────────┐
│ syswall-ebpf (userspace)                    │
│  EbpfProcessResolver : ProcessResolver      │
│  - async reader (tokio) on ring buffer      │
│  - maintains HashMap<(proto,local_port), pid>│
│  - enriches with /proc/{pid}/exe, cmdline   │
│  - icon resolution via IconResolver         │
└─────────────────────────────────────────────┘
```

### New crate: `syswall-ebpf` / Nouveau crate

- **BPF program** (`syswall-ebpf-prog/`): Rust eBPF program compiled with `aya-bpf`
  - Hook: `tracepoint/sock/inet_sock_set_state`
  - Captures: pid, tgid, comm (16 bytes), protocol, sport, dport, family (IPv4/IPv6)
  - Output: ring buffer (`BPF_MAP_TYPE_RINGBUF`, 256KB)
  
- **Userspace** (`syswall-ebpf/`): implements `ProcessResolver` trait
  - Loads BPF program via `aya::Ebpf`
  - Spawns async tokio task to drain ring buffer events
  - Maintains `DashMap<(Protocol, u16), ProcessInfo>` for fast lookups
  - `resolve_by_connection()` does O(1) lookup in the map
  - Enriches PID with `/proc/{pid}/exe`, `/proc/{pid}/cmdline`, icon

### Fallback strategy / Stratégie de fallback

```rust
pub struct HybridProcessResolver {
    ebpf: Option<EbpfProcessResolver>,
    procfs: ProcfsProcessResolver,
}

#[async_trait]
impl ProcessResolver for HybridProcessResolver {
    async fn resolve_by_connection(...) -> Result<Option<ProcessInfo>> {
        // Try eBPF first (fast, reliable)
        if let Some(ref ebpf) = self.ebpf {
            if let Ok(Some(info)) = ebpf.resolve_by_connection(...).await {
                return Ok(Some(info));
            }
        }
        // Fallback to procfs 3-tier
        self.procfs.resolve_by_connection(...).await
    }
}
```

At daemon startup: attempt to load eBPF. If it fails (missing CAP_BPF, old kernel, no BTF), log a warning and continue with procfs-only.

Au démarrage du daemon : tente de charger eBPF. En cas d'échec (pas de CAP_BPF, ancien kernel, pas de BTF), log un warning et continue avec procfs seul.

### Systemd changes / Modifications systemd

Add capabilities: `CAP_BPF`, `CAP_PERFMON`

### Kernel requirements / Exigences kernel

- Linux >= 5.8 (ring buffer support)
- BTF enabled (`CONFIG_DEBUG_INFO_BTF=y`) — standard on Arch, Ubuntu 22.04+

### Tests

- Unit tests with mock ring buffer events
- Integration test: load program, create TCP connection, verify PID captured
- Fallback test: simulate eBPF load failure, verify procfs takes over

## SP3 — Packaging / Empaquetage

### Arch Linux

**Local PKGBUILD** (`system/arch/PKGBUILD`):
```
pkgname=syswall
pkgver=0.2.0
pkgrel=1
pkgdesc="Application-level firewall for Linux desktop"
arch=('x86_64')
depends=('nftables' 'conntrack-tools' 'sqlite')
makedepends=('rust' 'cargo' 'nodejs' 'npm')
```
- Builds from local source (`makepkg -si`)
- Installs daemon binary, Tauri app, systemd service, desktop entry, default config

**AUR PKGBUILD** (`system/aur/PKGBUILD`):
- Sources from GitHub release tarball
- Includes `.SRCINFO` generated via `makepkg --printsrcinfo`
- SHA256 checksums
- `syswall.install` with hooks:
  - `post_install()`: systemctl daemon-reload, setcap on binary
  - `post_upgrade()`: systemctl daemon-reload, restart if running
  - `post_remove()`: systemctl stop, remove capabilities

### Deb improvements

- `system/deb/postinst`: daemon-reload, create syswall user, setcap
- `system/deb/postrm`: stop service, remove user on purge
- `system/deb/conffiles`: `/etc/syswall/config.toml`

### Rpm improvements

- `system/rpm/syswall.spec`: scriptlets %post/%preun/%postun
- Same logic as deb (user creation, capabilities, daemon-reload)

### Shared config file

`/etc/syswall/config.toml`:
```toml
[daemon]
default_policy = "block"
socket_path = "/run/syswall/syswall.sock"
log_level = "info"

[database]
path = "/var/lib/syswall/syswall.db"
wal_mode = true

[ebpf]
enabled = true
ring_buffer_size = 262144

[audit]
batch_size = 50
rotation_days = 30
```

## SP4 — CI/CD GitHub Actions

### `ci.yml` — On every push and PR

```yaml
jobs:
  lint:    cargo fmt --check && cargo clippy --workspace -- -D warnings
  test:    cargo test --workspace
  ui-check: cd crates/ui && npm ci && npm run check && npm run build
```

### `release.yml` — On tag `v*`

```yaml
jobs:
  build-daemon:    cargo build --release -p syswall-daemon
  build-ui:        cd crates/ui && npm ci && cargo tauri build
  package-deb:     extract from target/release/bundle/deb/
  package-rpm:     extract from target/release/bundle/rpm/
  package-arch:    run makepkg in container (archlinux/archlinux)
  github-release:  create GH release, upload all assets
```

### `aur.yml` — After successful release

```yaml
jobs:
  update-aur:
    - Update PKGBUILD with new version and sha256sums
    - Generate .SRCINFO
    - Push to AUR via SSH (secret: AUR_SSH_KEY)
```

### Required secrets

- `AUR_SSH_KEY`: SSH private key registered on AUR for push access

## SP5 — Security Audit / Audit sécurité

### Checklist

1. **systemd hardening**: run `systemd-analyze security syswall.service`, target score < 5.0
   - Verify: ProtectHome, ProtectSystem, NoNewPrivileges, RestrictNamespaces
   - Add: SystemCallFilter, RestrictAddressFamilies, MemoryDenyWriteExecute (where compatible with eBPF)

2. **Capabilities audit**: verify minimal set
   - Required: CAP_NET_ADMIN (nftables), CAP_SYS_PTRACE (/proc), CAP_BPF + CAP_PERFMON (eBPF)
   - Remove: CAP_CHOWN, CAP_FOWNER (if no longer needed after socket fix)

3. **gRPC surface**: Unix socket permissions (0660, group syswall), no TCP exposure

4. **Dependency audit**: `cargo audit` + `npm audit` in CI

5. **File permissions**: database 0600, config 0644, socket 0660

### Deliverables

- Hardened `syswall.service` with inline comments
- `cargo audit` and `npm audit` added to CI
- Security section in README

## SP6 — Performance Profiling / Profilage performance

### Benchmarks (criterion)

- `PolicyEngine::evaluate()` with 10/100/1000 rules × various connection types
- `EbpfProcessResolver::resolve_by_connection()` lookup latency
- `ConnectionService::process_connection()` end-to-end
- SQLite batch write throughput (audit events)

### Profiling

- Memory: track DashMap/LRU sizes under sustained traffic
- CPU: flamegraph with `cargo-flamegraph` under load
- Latency: measure time from conntrack event to UI display

### Stress testing

- Generate high-volume traffic with `iperf3` (TCP) and `hping3` (UDP)
- Verify no event drops in ring buffer
- Monitor daemon memory usage over 1h sustained load

### Optimization targets (if needed)

- Batch nftables rule updates (reduce nft invocations)
- SQLite connection pool with r2d2
- Connection deduplication (avoid re-processing established connections)
