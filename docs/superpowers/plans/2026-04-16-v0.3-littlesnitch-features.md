> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Tech Stack:** Rust (tokio, tonic/prost, nftables), SvelteKit 5, TypeScript, uPlot

- [ ] **Step 3: Implement TokioBroadcastEventBus::with_merge_window**

Add a `merge_window` field. When `merge_window > 0`, buffer `ConnectionDetected` events by connection ID. Spawn a flush task that drains the buffer every `merge_window` ms, keeping only the latest event per connection ID. All other event types pass through immediately.

```rust
pub struct TokioBroadcastEventBus {
    sender: broadcast::Sender<DomainEvent>,
    merge_buffer: Option<Arc<Mutex<HashMap<ConnectionId, Connection>>>>,
}

impl TokioBroadcastEventBus {
    pub fn new(capacity: usize) -> Self {
        Self { sender: broadcast::channel(capacity).0, merge_buffer: None }
    }

    pub fn with_merge_window(capacity: usize, window: Duration) -> Self {
        let (sender, _) = broadcast::channel(capacity);
        let buffer = Arc::new(Mutex::new(HashMap::new()));
        let buf_clone = buffer.clone();
        let sender_clone = sender.clone();

        tokio::spawn(async move {
            loop {
                tokio::time::sleep(window).await;
                let events: Vec<Connection> = {
                    let mut buf = buf_clone.lock().unwrap();
                    buf.drain().map(|(_, conn)| conn).collect()
                };
                for conn in events {
                    let _ = sender_clone.send(DomainEvent::ConnectionDetected(conn));
                }
            }
        });

        Self { sender, merge_buffer: Some(buffer) }
    }
}
```

In `publish()`, if merge_buffer is Some and event is ConnectionDetected, insert into buffer instead of sending directly.

```rust
/// Add a drop-all rule at priority 0 to block all traffic.
/// Ajoute une règle drop-all en priorité 0 pour bloquer tout le trafic.
pub fn drop_all(&self) -> Result<(), DomainError> {
    let cmd = format!(
        "add rule inet {} output priority 0 drop comment \"syswall-killswitch\"",
        self.config.table_name
    );
    self.run_nft(&cmd)?;
    let cmd_input = format!(
        "add rule inet {} input priority 0 drop comment \"syswall-killswitch\"",
        self.config.table_name
    );
    self.run_nft(&cmd_input)?;
    Ok(())
}

/// Remove the drop-all kill-switch rules.
/// Supprime les règles kill-switch drop-all.
pub fn remove_drop_all(&self) -> Result<(), DomainError> {
    // List rules, find handles with "syswall-killswitch" comment, delete them
    let output = self.run_nft(&format!("list table inet {} -a", self.config.table_name))?;
    for line in output.lines() {
        if line.contains("syswall-killswitch") {
            if let Some(handle) = line.rsplit("handle ").next().and_then(|h| h.trim().parse::<u64>().ok()) {
                let chain = if line.contains("output") { "output" } else { "input" };
                let _ = self.run_nft(&format!(
                    "delete rule inet {} {} handle {}",
                    self.config.table_name, chain, handle
                ));
            }
        }
    }
    Ok(())
}
```

- [ ] **Step 1: Create search query parser**

`crates/ui/src/lib/utils/search-parser.ts`:
```typescript
export interface SearchFilters {
  app?: string;
  dest?: string;
  src?: string;
  port?: number;
  sport?: number;
  dport?: number;
  proto?: string;
  verdict?: string;
  direction?: string;
  state?: string;
  user?: string;
  hostname?: string;
  freeText?: string;
}

export function parseSearchQuery(query: string): SearchFilters {
  const filters: SearchFilters = {};
  const freeTextParts: string[] = [];

  for (const token of query.split(/\s+/).filter(Boolean)) {
    const colonIdx = token.indexOf(':');
    if (colonIdx > 0) {
      const key = token.slice(0, colonIdx).toLowerCase();
      const value = token.slice(colonIdx + 1);
      switch (key) {
        case 'app': filters.app = value; break;
        case 'dest': filters.dest = value; break;
        case 'src': filters.src = value; break;
        case 'port': filters.port = parseInt(value, 10) || undefined; break;
        case 'sport': filters.sport = parseInt(value, 10) || undefined; break;
        case 'dport': filters.dport = parseInt(value, 10) || undefined; break;
        case 'proto': filters.proto = value; break;
        case 'verdict': filters.verdict = value; break;
        case 'direction': filters.direction = value; break;
        case 'state': filters.state = value; break;
        case 'user': filters.user = value; break;
        case 'hostname': filters.hostname = value; break;
        default: freeTextParts.push(token);
      }
    } else {
      freeTextParts.push(token);
    }
  }

  if (freeTextParts.length > 0) {
    filters.freeText = freeTextParts.join(' ');
  }
  return filters;
}
```
